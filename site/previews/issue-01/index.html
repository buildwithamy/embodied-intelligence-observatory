AMD 买下 World Labs：做芯片的，开始自己养世界模型

9 月 28 日，AMD 宣布以约 82 亿美元股票收购李飞飞创办的 World Labs。三周前，这家公司刚发布空间模型 Atlas，能把文字、图片、视频和 3D 放进同一个空间里理解和生成。两家早就在 AMD 的 GPU 上一起训练模型，这次干脆合为一家。AMD 的算盘很清楚：先弄懂机器人和仿真要什么样的算力，再回头设计芯片和软件。交易预计年底前完成。

研发
世界模型这条线，过去几乎只有 NVIDIA 一种跑法。ROCm 上接下来会多出一批空间模型和仿真工具，值得留一只眼睛。
产品与项目
手上的选型不用动。2027 年做算力采购评审时，看 AMD 有没有拿出成套的机器人软硬件方案。
教育
拿来讲一堂课正合适：芯片公司为什么要买模型公司，算力、模型、仿真谁离不开谁。

MoveIt 和 RealSense，同一周换了主人

机器人开发者最常打开的两样工具，在本期开始前一周相继易主。高通收购 MoveIt 的主要维护者 PickNik，承诺 MoveIt 继续开源，并会和自家 Dragonwing 平台、Arduino 开发板打通。Cognex 花约 5 亿美元买下 RealSense，深度相机并入工业视觉产品线。同一周，软银从现代汽车手里接过 Marc Raibert 的 RAI Institute，交易还在等美国外资审查。

研发
代码短期不会变。真正要盯的是发版节奏和驱动维护，依赖这两样的项目，现在就该把备选方案列出来。
产品与项目
把 MoveIt 和 RealSense 写进供应商风险清单，新合同里注明 SDK 支持年限。
教育
课照常上。用 RealSense 的实验室，采购时把 SDK 支持年限写进合同，再备一套替代相机的实验。

同样 200 条示范，两种策略谁更强？
4 学时本科高年级 / 研究生练的是：数据采集 + 算法评测
  1. 用 SO-101 遥操作采 200 条“抓取—放置”，另采 50 条当考卷。
  2. 分别微调 SmolVLA 和 FLUX 3 Action。
  3. 同一张考卷上，记完成率、接管次数和推理延迟。
  4. 挑三个失败案例，写清是看错了、抓偏了还是放歪了。
准备与打分
  • 硬件：SO-101 一套，训练卡一张。
  • 软件：LeRobot；用 FLUX 前先读许可证。
  • 打分：数据质量 30%，实验设计 30%，结果分析 40%。
  • 加分题：示范数改成 50 / 100 / 200，画出学习曲线。
