# W40 中文表达试改

本文记录 DeepSeek 润色之前的手工试改。后续采用稿及实际 API 用量见[DeepSeek 中文润色记录](deepseek_polishing.md)。

本次检视针对中文流畅性。以下记录最初的三组候选改写。2026 年 10 月 6 日，用户确认采用该风格，Codex 已据此完成整期语言修订，更新网页和 Markdown 归档；没有调用 DeepSeek 或其他付费模型 API，也不是多模型评测结果。

## 现有技能的适用程度

Humanizer 适合检查套话、重复句式和空泛强调，但其英文写作经验不能直接代替中文技术编辑。上一轮部分句子被拆得过短，省略了应有的主语与解释，削弱了连贯性。

dbs-ai-check 包含中文翻译腔和句式重复的诊断，但默认输出检测报告；它不是事实约束下的技术改写流程。dbs-script-flow 面向短视频口播，luxun-review 面向文章点评，两者的体裁和用途也不完全匹配本刊。

本项目采用独立的[中文技术编辑提示词](../prompts/chinese_technical_editor.md)，让已有模型或 DeepSeek 使用同一组表达要求和技术边界。该文件是项目内规范，尚未安装为全局自动发现的 skill。

## 样例一：说明评测边界

字段：signals[0].meaning。改写参考同一信号及 homes 正文的已核读事实。

原文：

> 任务学过，房间没见过。评测的边界要分清。

候选：

> 模型此前已使用其他环境中的真机数据，针对这三项家务做过微调；此次评测检验的是对新家庭环境和物体的泛化能力。

修改目的：将两句口号改为完整解释，让读者知道“未见”指什么。任务微调和环境、物体泛化的区别保留；没有推断模型能完成从未训练过的任务。

## 样例二：交代预训练对照

字段：stories[0].paragraphs[1]。

原文：

> 在任务微调数据等条件相同的比较中，公司报告：使用 Index 预训练后，完整任务成功率从 9% 提高到 56%。这是环境与物体泛化的测试，任务本身并非从未学过。

候选：

> Figure 报告，在任务微调数据等条件相同的对照中，加入 Index 预训练后，完整任务成功率从 9% 提高到 56%。这项评测考察模型对新环境和新物体的泛化能力，三项家务本身仍经过微调。

修改目的：先交代结果归属，再说明比较条件与指标；后一句接着解释结果适用于什么。9%、56%、完整任务成功率、相同微调数据条件和公司报告归属均保留。

## 样例三：区分两项指标

字段：stories[4].paragraphs[1]。

原文：

> WorldLine 用动作条件的视觉预测筛选候选轨迹。作者报告，在固定候选预算的规划实验中，任务成功率提升最高为 21.4 个百分点；轨迹成功预测的平均准确率为 74%，这是另一项指标。

候选：

> WorldLine 根据候选动作预测视觉结果，用这些预测筛选轨迹。作者报告，在候选预算固定的规划实验中，任务成功率最高提升 21.4 个百分点。另外，模型判断轨迹是否会成功的平均准确率为 74%；这个数字衡量预测是否准确，不能直接当作任务执行的成功率。

修改目的：解释预测怎样参与选择，再把执行效果和预测效果分别说清楚。保留固定候选预算、“最高”、21.4 个百分点、74% 的平均预测准确率和作者归属。没有把所有实验描述为都提高 21.4 个百分点，也没有将 74% 描述为执行成功率。

## DeepSeek 试用方式

先对以上三个完整编辑单元做小样本比较。向模型提供原文、同一单元的必要上下文、来源摘录及事实约束；只发送本刊公开资料和编辑内容。

DeepSeek 返回修改候选；Codex 逐条对照证据，比较主语、语序、衔接是否改善，以及数字与指标、比较条件、结论范围、消息归属和不确定性是否保留。保留原文、候选、采用结果与理由，不按改字数量评价质量。遇到资料歧义先核实，不要求模型补全。

采用条件：无需回读即可理解，关键技术含义保留，没有新增无依据断言。样本改善明显后再扩大到正文，最后单独检查首屏长短和手机换行。

项目现有 llm.py 使用可配置端点的 Chat Completions 与 JSON 输出，事实分析默认也会经过独立核查。语言编辑应单独配置和保存候选，避免混用事实分析缓存或覆盖证据。本次没有新增 API 调用命令或改变已有模型配置。

接入时，在本机私下配置 DEEPSEEK_API_KEY，另行确认 API 地址和可用模型名；密钥不要写入正文、日志或聊天。尚未配置和授权实际调用时，继续用 Codex 执行相同编辑规范。

接口参考：[DeepSeek JSON Output 官方说明](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)。JSON 输出只能保证结构方面的要求，不能保证技术内容正确。

## 采用后的修订范围

修订覆盖首屏导语、三条核心消息、速读、五篇重点、应用与教学建议、研究问题、学习练习，以及六篇折叠论文笔记。标题采用具体内容，正文补清主语和比较条件；适合保留的短句与专业术语没有强行改写。

154 个编辑字段的原文、采用稿和修改理由保存在 runs/2026-W40-chinese-edit.json。原编辑稿保存在 data/editorial/history/2026-W40-v03-before-chinese-edit.json，原论文解读保存在同目录的 2026-W40-before-chinese-edit.json。修改前后核对了数字、指标归属、实验条件、范围和不确定性，原始证据、来源信息、事件审计快照与引用保持不变。

学习练习中明确了“固定新增示范总预算”：均匀分配与针对失败环节分配是对照变量；不能同时要求每项技能始终获得同样数量的示范。这是练习表述的澄清，没有新增论文实验结论。
