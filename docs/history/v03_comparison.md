## 1. V0.1 为什么像研究记录

原首屏五条速览全部是论文，焦点又指向其中三篇。完整正文逐项展开研究问题、方法、结果、局限，并显示body ID、阅读层级与置信度；产业栏是采集覆盖不足说明。534条原始记录中论文占绝大多数，最终7条里有6篇论文、1条MIT技术新闻。流程重视证据，却没有把读者最先想知道的企业、产品和场景变化放在前面。

## 2. 如何体现 A > B > C

Hero先给编辑判断和三个变化：家庭泛化评测、商业部署的安全与运营、开发平台中的系统验证。桌面和390px手机首屏都可看到三条核心标题及事实。

前五部分依次为Hero、7条混合速读、8节点时间线、5个Top Stories、Impact Radar。研究问题与六篇论文在后部，长笔记默认折叠。每个重点事件先解释发生了什么，再说明应用与教学意义，研究追问最多2条。四类原创信息视觉分别承担时间顺序、技术与场景对应、转化路径、精选论文主题计数；不使用装饰机器人图片。

## 4. Major Event Memory

10条已核实事件进入记忆：上表8条加MuJoCo 3.14（09-22）、武汉晴川学院培养方案（09-10）。本期2条Weekly New、6条Recent Major；无Persistent Major，原因是本轮有效事件均在30天内。两条B级超过当周保留期，状态为archived，正文快照没有删除。

支持S60天/A45天/B7天保留；超过30天保留需continuation_reason。重复导入保留first_seen与旧来源，拒绝事件身份或事实更新日期倒退；未来日期、未确认事件和归档事件不入刊。每期审计保存event_snapshot，网页从该期快照重建。继续/排除/归档记录在memory_decisions，普通Collector未收录的8事件均有复核队列与已确认结果。

## 5. 有效应用启示

- 工业：工具操作、位姿与规划集成、维护和训练中心；下一步看节拍、停机恢复与班次绩效。
- 物流：Digit安全路线与外部互锁接口；下一步看交付、现场安全和负载。
- 零售服务：园区/门店导引与转人工；下一步看服务完成率、接管、有效工时与ROI。
- 家庭服务：未见家庭泛化、隐藏状态记忆；养老照护只列延伸方向，无本期实证。
- 通用人形：跨本体行为复用、形态差异与手部维护；需要完整适配成本。
- 教育科研：跨仿真、日志、标准阅读和复验；需硬件与课程前置能力。

医疗、环卫、边防、农业没有足够本期信号，未硬凑栏目。矩阵展示六个相关场景、五类技术，使用直接对应/潜在关联/无支持三种定性标记，不做成熟度打分。

## 6. 教育启示

教育由技术变化与部署问题导出，不靠当周教育新闻撑栏目。三项学习概念：部分可观测与有效记忆；世界模型与预算对照；跨条件验证与系统集成。分别给课程位置、前置知识和可执行练习，连到CS285、MIT机器人教材、LeRobot等持续资源。

建议机器人基础、控制与ROS作为底座；POMDP进入学习模块；世界模型与跨本体放高年级前沿；跨后端复验、端到端测时、安全互锁和失败恢复进入实验验收。晴川单校培养方案已核读并存档，未把方案发布等同专业新批准或教学成效；本期没有将普通旧教育新闻升为行业重大变化。

## 7. Research Radar 保留的问题

1. 世界模型的选择增益，计入判断器、推理时间与真实执行误差后还剩多少？复查RoboCoach的示范预算与WorldLine的候选预算。
2. 技能记忆究竟存什么？在HIDE按任务做窗口、锚点、进度消融，加入相同当前观测/不同历史对照；APPL补充技能组合接口。
3. 跨本体、跨仿真究竟节省哪部分成本？复查CrossBFM的M3/T1落差，算上控制器、适配与验证；Isaac Lab补跨后端实验。

六篇精读：RoboCoach、WorldLine、HIDE/SEEK、CrossBFM、APPL、机器人ICL综述。主题图计数2/2/1/1仅属这六篇精选样本，不构成30天全量研究趋势或热度增长。
