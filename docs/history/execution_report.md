## A. 实现内容

| 模块 | 实现与边界 |
|---|---|
| 论文采集 | robotics累计JSON周界提交快照ID差；HF逐日API；arXiv批量补元数据和摘要页备用 |
| 非论文采集 | 官方RSS/Atom、GitHub Releases分页、教育部可见列表+详情，独立隔离失败 |
| Schema | Candidate、Evidence、Scores、Analysis采用Pydantic；保存出版/获取时间、源列表、原始URL、证据及字段级引用 |
| 标准化/去重 | arXiv去版本、URL去追踪参数、标题规范化；ID/DOI/URL/标题回退；合并来源与证据；不同arXiv ID不按同题误并 |
| 相关性与评分 | 可配置五维权重、阈值和栏目上限；规则预筛明确标记临时评分；可选模型分类评分或人工解读导入 |
| 大新闻兜底 | watchlist按机构、事件、政策与专业建设生成二次检查队列；标记不等于验证或自动入选 |
| Research | 重点论文arXiv正文、官方新闻正文；不足时标记摘要层级或失败，不仅凭标题解释 |
| AI分析 | 独立Prompt、JSON Schema、字段级证据、事实检查；API模式明确启用；本期为Codex来源核验导入 |
| 编辑/输出 | 确定性renderer组织七个栏目、速览/焦点、原文链接、资源索引；没有合格信息时说明缺口 |
| CLI | collect / analyze / report / weekly / publish / cache-clear；日期范围、offline、refresh与dry-run |
| Draft→Publish | 显式维护者`--reviewed`命令与结构化审核门槛；仅该命令写reports/latest，不操作Git |
| 缓存/日志 | HTTP有限重试、TTL、公开body缓存；分析按模型/Prompt/Schema/内容hash；INFO/WARNING/ERROR与manifest |
| 测试/文档 | 42项离线测试、Ruff、真实weekly、真实缓存Dry Run；README、架构、编辑政策、运行和来源语义文档 |

采用简单src布局，没有重型前端、数据库服务、复杂Agent框架或常驻服务。针对独立公开来源的实现调研使用了小规模临时子任务协作，不作为产品运行依赖。

## E. AI 调用与核验范围

**脚本本期模型API调用为0。** 没有检测到API Key，未凭空生成摘要，也没有以程序API零调用冒充「整个任务不用模型」。本对话中的Codex读取重点论文方法、实验与局限片段以及MIT官方正文，编写7份结构化解读，明确标记`origin=codex_review`；未复现实验、未穷尽附录或综述全部被引文献。

没有用模型做网络请求、日期、标准化、去重、文件存储与报告渲染。`--llm`实现兼容Chat Completions的分类、评分、解读、独立事实检查，模型与Key由环境变量显式指定。API层有离线模拟的Schema、用量、缓存与secret测试，尚未在真实付费API上验证；这是已知限制。

作者报告与官方声明保留归属。WorldLine的成功预测准确率不写成执行成功率；CrossBFM保留不同本体迁移落差；APPL标为仿真实验；MIT游泳原型明确外部光控，未写成自主商业系统。

## F. 第一份周报质量观察

较好：出版与发现日期分开、真实作者与ID、双源去重、方法/结果/判断/局限分开、非标题解读、全部入选项保留原文证据。3个焦点覆盖主动示范、视觉模拟的决策用途与隐藏状态记忆，有可读的工程价值判断。

不足：产业与正式Release为空；教育栏目只有覆盖说明与3个已核验持续资源（明确非本周新增），国内教育新闻失败。不能声称教育动态已经稳定捕获，也不能将空结果理解成行业平静。国内企业、国家政策、高校正式专业与大额订单尤其可能漏报。

## G. 成本

本期脚本模型API：0次，API输入/输出tokens均为0，无额外脚本模型账单。Codex本对话用量另计，无法由工程manifest精确归属或估价。

启用API时，每个规则命中或大新闻待审候选一次分类评分，每个入选项再各一次分析和事实检查。以本期约195个待查项、7个入选项估算，首次可能约209次请求，最终数量取决于模型筛选，失败调用也计入请求次数；不应默认低成本。正文/摘要是主要token消耗。

缓存避免重复付费，重跑的获取时间不参与分析内容hash；限制精选数量与更精确的预筛可降低费用，改Prompt/模型会失效重算。manifest未配置模型费率，`estimated_cost_usd=null`，不猜供应商价格。必要时优先人工/Codex导入而非降低事实要求。
