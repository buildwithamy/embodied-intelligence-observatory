# W40 阅读与视觉改进

本轮围绕“首屏愿意停下来，正文愿意读下去”调整。事实窗口、8条展示事件、6篇论文与一手证据保持不变；网页和Markdown归档同步更新。

## 改进判断

上一版已经把大新闻放在论文前面，但首屏的“跨环境与持续运行”较抽象。正文每段长短和标题顺序接近，来源英文全称又重复占据很多空间。信息齐全，阅读节奏仍像逐项填写的模板。

这轮封面抓住一个具体问题：“换个房间，机器人还会做吗？”它来自Figure的30家庭评测，读者可以直接理解，也能顺着问到环境泛化、失败与真实部署。物流与商业部署、开发工具两条主线仍放在首屏，点标题直达对应重点。

## 文字复审

先改写导语和五篇重点，再读一遍，检查是否还有抽象意义、整齐口号、刻意对比与同义词轮换。没有添加虚构人物、采访或第一人称经历；“我们想看”表示编辑追问，数字仍注明公司或作者归属。

| 原稿 | 第一轮改写 | 复审后采用 |
|---|---|---|
| 机器人走出单次演示，下一关是跨环境与持续运行。 | 机器人能否在陌生家庭完成家务？ | 换个房间，机器人还会做吗？ |
| 走进30个家庭，泛化评测开始回答更具体的问题 | 家庭泛化，需要更多失败数据 | 56%之外，我们想看剩下的任务 |
| 国内服务场景有了新的公开部署披露 | 国内服务部署值得看运营效果 | 300多台机器人，运营账怎么算？ |
| 训练平台可以换物理引擎，课程也该换一种验收方式 | 跨仿真验证要进入实验流程 | 换一个物理引擎，策略还稳不稳？ |
| 把变化读深一层 | 重点消息深读 | 这期重点 |

第一轮仍有“需要”“值得”“进入流程”等泛泛判断，最终标题改为具体问题。正文保留长短不同的句子，直接说公司做了什么、测试怎么比、下一个数据缺口在哪。删除重复的“发生了什么 / 为什么现在重要”标题；应用、课堂和关键边界保留较轻的旁注。主题图与研究数量来自精选样本，未升级为全行业趋势。

## 三张原创图

1. **封面家庭任务示意**：房间、机器人、沙发、毛巾、床组成等角场景，30格表示30个测试家庭。所有户型与机器人为概念绘图，图注明确不是现场或真实户型；格子颜色不表示各家庭成绩。
2. **Helix完整任务成绩图**：依据Figure原文重绘9%与56%，横轴从0至100%，标明Index预训练对照、任务微调条件、公司自评和未独立复现。
3. **世界模型的两个决定**：RoboCoach根据预测失败选择新增示范，WorldLine根据候选轨迹选择动作。图中箭头表示步骤，没有把两套研究成绩合并比较。

两张正文图各有手机竖版。SVG源码位于templates/figures，随构建复制到site/assets；每张图的来源引用与文件SHA256记入runs/2026-W40-v03.json。图注与放大链接保留在网页，Markdown归档使用正确的相对图片路径。本轮全部采用原创矢量图，没有转载外部图片。

## 阅读节奏与版面

- 封面采用深绿标题区与浅色原彩图，正文继续用纸色背景和本地衬线字体。
- 桌面正文16px，手机15px；正文行距1.95，主文字控制行长。速读与正文来源改为12px的简称，完整标题留在title、aria-label与来源索引。
- 时间线只给简短事件摘要，展开内容在重点解读里。公司与工具备忘默认折叠，减少再读一遍同一条消息的负担。
- 论文继续按需展开；手机矩阵在自身区域滑动，不让整页横向溢出。
- 封面三条标题可直接进入对应解读。回到页面顶部时，导航清除过期的章节标记。
