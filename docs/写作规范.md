# 写作规范

适用于期刊正文、网站首页、README 和对外发布的文字（包括社交媒体）。目标是让工程师、产品/项目经理和教育工作者一读就懂，信息准确、可以核查。

本规范于 2026-10-07 定稿，依据是第 1 期按一流中文媒体标准的全文修订。它取代 V2 方案里“像杂志编辑那样写”的要求；与 [EIO_改进方案_V2.md](EIO_改进方案_V2.md) 第四节不一致时，以本文为准。

## 一、初心

持续跟踪高质量的一手信源，筛出价值最高的新闻和落地案例，从读者关心的角度拆解。对外介绍项目时，先讲这条方法，再讲栏目。

## 二、标题

- 写成一句完整、好懂的中文：有主语、有动作，关键信息放在前面。
- 不用电报体和名词堆砌，不用比喻、对仗和设问。
- 期刊总标题 20 字左右；栏目标题和条目标题尽量在 25 字以内。

| 改前 | 改后 |
|---|---|
| 人形机器人部署：台数公开了，日工时和接管率没有 | 人形机器人陆续落地，干了多少活几乎没人公开 |
| 人形机器人落地的两本账：中国在数台数，美国在算单台账 | 同上 |
| 芯片巨头下场，工具箱换了主人 | 三笔收购，涉及世界模型、MoveIt 和 RealSense |
| 台数的六级口径：产能、订单、出货、部署、在岗、有效工作 | 厂商公布的“台数”，到底指什么 |
| 六个格子，看每个部署露了多少底 | 6 个部署案例，各自公开了哪些数据 |
| 九所高校开招，第一节实验课怎么上 | 具身智能首次进入本科专业目录，9 所高校今年开始招生 |

## 三、导语和正文

- 先写事实，再写判断。判断最多一句，放在最后；推测要写“可能”“很可能”。
- 句子短，一句只说一件事。
- 厂商的说法标明归属：“厂商称”“公司测算”“据媒体估算”。
- 每条按固定字段写：是什么（版本、参数、许可）；能不能用（价格、获取方式、硬件要求）；对研发、产品与项目、教育各有什么影响；还缺什么证据。
- 不用口语和俏皮话，例如“算盘很清楚”“留一只眼睛”“遥操作的钱，该这么花”。
- 不用套话，例如“值得关注”“意味着”“赛道”“风口”“赋能”；不用破折号插入语。

## 四、术语

- 专业术语第一次出现时，用中文说清含义，必要时在括号里附英文缩写，例如 VLA（视觉-语言-动作模型）、BOM（物料成本）。
- 固定用词：

| 用 | 不用 |
|---|---|
| 人工接管率 | 接管率、干预率混用 |
| 每日工时 | 日工时、干多久 |
| 实际工作效率 | 干活效率 |
| 测试集 | 考卷 |
| 已公开 / 未公开 | 露底、没说 |
| 付费方式 | 谁付钱 |

- 产品和模型名保留原文：Digit 5、FLUX 3 Action、Isaac ROS 5.0。

## 五、公司和人名

- 有通行中文名的用中文名：波士顿动力、英伟达、微软、谷歌、特斯拉、康耐视、泰瑞达、高通、软银、丰田、舍弗勒。需要时在括号里附英文，例如康耐视（Cognex）。
- 没有通行中文名的保留英文：Agility、Figure、World Labs、PickNik、Maven Robotics。
- 国内公司用通行简称：智元、银河通用、优必选、宇树。同一句里不要重复同一个词，例如“智元机器人把 300 多台机器人”。
- 外国人名保留原文：Rohit Prasad、Marc Raibert。

## 六、数字和单位

- 正文、表格和卡片里的金额用“万、亿”：约 2.5 万美元、2.25 亿美元、7.9 万元；不写 $25k、$225M。
- 写明币种；人民币和美元折算时注明汇率。
- 约数写“约”。图表、数字条可以用“≈”。
- 日期写全：“2027 年 4 月 1 日起实施”，不写“明年”；区间写作 09.24–10.07。
- 单位用公斤、米、小时、毫秒；英制单位附公制换算，例如 50 磅（约 23 公斤）。
- 图表坐标轴、计算器输出这类空间受限的地方，可以保留 $ 和 k，但要在图例或说明里注明单位。

## 七、标点和排版

- 用中文全角标点和中文引号“”。
- 中文与英文、中文与数字之间加空格，例如“82 亿美元”“SO-101 机械臂”。
- 并列成分用顿号；不用“/”代替“或”。

## 八、证据标注

- 每条标证据等级：官方（公告、监管文件、论文）、公司自述（演示、投资者材料）、媒体（尚未核实到一手来源）、说明（评测范围或观点）。
- 厂商没有公开的数据写“未公开”，表格里画斜纹，不替厂商补数。
- 口径不同的几组数字并列呈现，写明来源，不替读者下结论。

## 九、发布前自查

1. 不了解背景的读者，能不能一读就懂标题？
2. 有没有电报体、比喻、口号和俏皮话？
3. 术语是否统一，第一次出现时有没有解释？
4. 公司名、金额和单位是否符合中文习惯？
5. 每个判断有没有依据和归属？
