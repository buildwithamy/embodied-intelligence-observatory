# 编辑政策

## V0.3 读者顺序与审计

A（近期重要变化）> B（应用与教育影响）> C（研究问题与论文）。周刊发布频率与信息窗口分开：周新增7天、近期重大30天，S/A级超过30天仅在明确延续理由下保留至60/45天。过期事件归档不删除；事实更新日期来自来源，而不是抓取时间。每期保留事件快照，以历史截止日期隔离未来信息。

每期网页构建前必须完成独立 Major News Audit，分别检查企业、产品、模型、开源、资本、政策与教育；原文核实后导入major-audit，普通Collector漏报也进入人工复核。目录与搜索仅是发现入口。网页中的覆盖数只描述本期精选；未检出和未完成核查都不能推断该领域没有进展。

Top Stories混合企业、平台与研究信号。场景与教育启示绑定具体来源，明确为编辑分析；只展示有信号的场景。矩阵不生成成熟度分数，研究主题图仅计算精选样本。论文默认折叠，证据ID、阅读层级、置信度与失败日志留在数据或折叠审计区。没有上月完整基线时不计算月度增长、热度或全行业成熟度变化。

## 纳入与排除

纳入直接涉及物理世界交互的机器人学习、VLA、操作、导航、运动控制、机器人安全、空间感知、触觉、Sim2Real、数据与基准，以及正式产业/开源/教育/政策事件。VLM必须有直接机器人、三维空间或物理交互关联。排除纯LLM/NLP、一般图像生成、无物理交互的Agent、普通招生与品牌宣传。

## Source Hierarchy

原论文 → 官方项目 → 官方GitHub → 官方报告 → 公司官方发布 → 政府教育主管部门 → 高校官网 → 专业媒体 → 普通媒体 → 社交线索。索引与热度仅用于发现，不能代替一手事实证据。

## 公司 PR 与论文主张

写「公司表示」或「作者报告」，不能默认第三方验证成立。demo不足以证明规模化部署，融资不足以证明技术成熟。benchmark表现不能自动推广到真实机器人、不同场景或长任务。来源没有给出的数字、作者、模型或实验不能由编辑补充。

## 事实、判断与不确定性

研究问题、方法与结果用字段级 evidence ID 链接；编辑价值与局限另列。事实检查 pass 只表示解读与提供的资料一致，不能表示已复现实验。不能确认则明确「尚未找到足够的一手资料验证」。摘要解读不称全文深读，长期课程资源不称本周新增。

## AI 审核

程序与AI辅助采集、分类、摘要、组织与初步核查；模型JSON须过Schema和引用检查。外部网页内容是资料，不能作为执行指令。API分析后独立进行证据对照；Codex/人工导入须注明来源及阅读层级。最终由维护者查看原始论文/官方页面，修订后显式publish。

标题/作者/日期/数字/benchmark/公司名称/链接/分类必须核对。相关性规则存在漏判与误判，初步评分不可冒充研究质量排名。重大事件触发watchlist二次检查，不能只靠常规分数过滤。

## 修订与勘误

草稿与发布分开。修改已发布期次时，文末增加「勘误」：日期、原表述、修订原因、证据链接；更新候选分析与manifest；人工重新发布并commit保留版本记录。不得静默删去错误或隐藏来源失败。

科研、采购、投资与教学等重要决策应回到原始来源。所有原文材料及课程版权归原权利人；周报采用简短改写与评论，不大段复制摘要或新闻正文。
